# Security Policy

## Supported Versions

Currently, the latest version of KrishiAI is supported with security updates.

| Version | Supported |
|---|---|
| Latest | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in KrishiAI, please report it privately.

Please do not publicly disclose the vulnerability before it has been reviewed.

You can report security issues by contacting the repository owner through GitHub:

**GitHub:** @veereshmv88

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce it
- Potential impact
- Screenshots or logs, if applicable
- Any suggested fix, if available

## Response

Security reports will be reviewed and investigated as soon as reasonably possible.

Please allow time for the issue to be verified and addressed before publicly disclosing it.

## API Keys and Secrets

API keys, passwords, tokens, and other private credentials must not be committed to this repository.

Local/private configuration should be stored outside the Git repository and excluded using `.gitignore`.

If a credential is accidentally exposed, it should be revoked or rotated immediately.
